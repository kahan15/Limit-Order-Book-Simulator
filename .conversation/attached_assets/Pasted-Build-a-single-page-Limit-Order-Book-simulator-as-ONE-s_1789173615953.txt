Build a single-page Limit Order Book simulator as ONE static index.html file with
inline CSS and JS. No frameworks, no build step, no npm packages, no backend, no database.

DATA MODEL
- Order: {id, side: 'buy'|'sell', price, qty, ts}
- Book has two sides. Bids sorted price DESCENDING, asks sorted price ASCENDING.
- Each price level holds a FIFO queue of orders (price-time priority).

MATCHING RULES (implement exactly)
- LIMIT order: while it crosses the opposite best (buy price >= best ask, or sell price
  <= best bid) and qty remains, match against the resting order at the front of the best
  level. Fill min(incoming.qty, resting.qty). Partial fills allowed: decrement both,
  remove the resting order at 0, remove the price level when its queue is empty. Any
  remaining qty rests on the book.
- MARKET order: sweep opposite levels best-first until filled or the book is empty.
  Leftover qty is cancelled, not rested.
- Trade price is always the RESTING order's price, never the incoming order's.
- The book must NEVER be crossed: after any operation, best bid < best ask.
- Cancel by order id: remove it from its level, clean up the empty level.

UI (dark theme, monospace numbers, green = bid, red = ask)
- Ladder table in the center: asks stacked above in DESCENDING price order, then a
  spread row showing best bid / mid / best ask / spread, then bids below in descending
  price order. Top 10 levels per side only.
- Ladder columns: Price | Size | Cumulative | Depth bar. The depth bar is a horizontal
  div whose width is (cumulative size / max cumulative on that side) * 100%, drawn
  right-to-left on the bid side and left-to-right on the ask side.
- Left panel: order entry with side (buy/sell), type (limit/market), price, qty, Submit.
  Price input disables when type is market. Also "Cancel order by ID" input, "Seed book"
  and "Clear book" buttons.
- Right panel: trade tape, last 20 trades, newest first: time, price, qty, aggressor
  side colored green/red.
- "Seed book" generates ~20 resting orders per side around mid 100.00, tick size 0.01,
  random sizes 10-500, leaving a spread of a few ticks.

Re-render ladder and tape after every action. Keep logic in plain functions
(addLimitOrder, addMarketOrder, cancelOrder, render) so it's easy to extend.
